Multi-instance monitoring for SQL Server, Azure SQL Database, and SQL Managed Instance.

Independent software, no warranty

Created by Luis Fernando Borbon as an independent project. Not an official Microsoft or GitHub product, and not affiliated with or endorsed by either company. Provided as-is, without warranty or support commitment, under the MIT License. Use at your own risk.

Production safety and permissions

Connect only to systems you are authorized to access. Use least-privilege accounts and appropriate DMV permissions. Collection is read-only, but polling and custom counters can add workload. The manual Kill Session action changes server state and can interrupt work or trigger rollback; it requires explicit confirmation and SQL permissions. Generated index and plan scripts are suggestions, not automatic changes. Review and test them before production use.

AI privacy and charges

AI answers may be incomplete or incorrect and are not a substitute for qualified review. Cloud or network providers receive the approved question and SQL context, which can include query text, database names, and measurements. Review the exact payload and destination before every send. Do not disclose confidential data unless your organization permits it. Provider retention, licensing, quotas, and charges apply. A local endpoint does not guarantee that its model never makes network calls. AI has no SQL execution or system tools in this app.

Local data and diagnostic limits

Saved passwords and API credentials are encrypted with AES-256-GCM and a Windows DPAPI-protected key. Registry metadata, history, and browser snapshots are not encrypted by this app. Protect the Windows account, data folder, and backups. Metrics can be delayed, cumulative, or unavailable because of permissions. Health indicators are heuristics, not availability, backup, or recovery guarantees.
